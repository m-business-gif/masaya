# サロンボード クーポン自動並び替え

直近の予約実績があるクーポンをサロンボードの表示順で上位に自動的に並び替えるスクリプトです。
毎週月曜 06:00 (JST) に GitHub Actions で自動実行されます（`.github/workflows/salon-board-coupon-reorder.yml`）。

## 重要：使い始める前に

1. **サロンボードの利用規約を確認してください。** 本スクリプトはサロンボードに実際にログインし、
   画面を自動操作（ブラウザ自動化）します。自動化ツールでのアクセスが規約上問題ないか、
   事前にご自身で確認してください。
2. **セレクタは未検証です。** `config/selectors.json` 内の `REQUIRES_VERIFICATION` と書かれた値は、
   このセッションから実際のサロンボード画面（ログインが必要）にアクセスできなかったため仮置きです。
   実行前に必ず下記の手順で実際の値に置き換えてください。置き換えないとエラーで停止します
   （安全側に倒す設計です）。
3. **最初は必ず DRY_RUN で試してください。** 誤った並び替えが本番のクーポン表示に反映されるのを防ぐため、
   `DRY_RUN=true`（デフォルト）では実際の保存を行わず、変更予定をログ出力するだけです。

## ルール

- 直近 `LOOKBACK_DAYS`（デフォルト7日＝直近1週間）に予約実績があったクーポンを表示順の上位にまとめます。
- 各グループ（予約あり／なし）の中では、元の表示順を維持します（不要な入れ替えを避けるため）。
- ログインしているアカウントが管理する**全サロン**を自動的に処理します（サロン一覧から取得）。
- `config/excluded-salons.json` に記載した名前を含むサロンは対象から除外されます（部分一致）。
  現在は以下を除外設定済みです。
  - 目黒
  - 【小顔・痩身】小顔専門店Lift(リフト)調布（旧：most eyes 調布）

## セットアップ

```bash
cd salon-board-coupon-sync
npm install
npx playwright install --with-deps chromium
cp .env.example .env   # .env に実際のID/パスワードを設定（絶対にコミットしないこと）
```

## セレクタの検証方法

サロンボードの画面構造（HTML）は実際にログインしないと確認できません。以下の手順で
`config/selectors.json` を埋めてください。

1. `npm run codegen` を実行すると、Playwright Inspector が起動しブラウザが開きます。
2. 実際にログイン画面・予約一覧画面・クーポン管理画面を操作すると、右側にセレクタ入りのコードが
   自動生成されます。
3. 生成されたセレクタを `config/selectors.json` の対応する項目に反映してください
   （ロジック本体 `src/*.js` は変更不要です）。
4. 特に以下を確認してください。
   - ログイン成功後に表示される、ログイン失敗時には出ない要素（`login.successIndicator`）
   - 予約一覧で「クーポン名」が表示されているセル
   - クーポン管理画面で表示順を編集する入力欄（数値入力かドラッグ&ドロップかで実装が変わります。
     ドラッグ&ドロップ方式の場合は `src/coupons.js` の `applyOrder` を要調整）

## ローカルでの試し方

```bash
npm run reorder:dry-run   # 実際の保存なし。ログで変更予定を確認
npm run reorder           # .env の DRY_RUN=false の場合のみ実際に保存
```

## GitHub Actions での運用

1. リポジトリの Settings → Secrets and variables → Actions で以下を設定してください。
   - `SALON_BOARD_LOGIN_ID` (Secret)
   - `SALON_BOARD_PASSWORD` (Secret)
   - `SALON_BOARD_DRY_RUN` (Variable, 任意): セレクタ検証・動作確認が終わるまでは `true` のままにし、
     問題ないことを確認できたら `false` に変更してください。未設定時は安全側の `true` として動作します。
   - `SALON_BOARD_LOOKBACK_DAYS` (Variable, 任意): デフォルト `7`
2. Actions タブから「サロンボード クーポン自動並び替え」を `workflow_dispatch` で手動実行し、
   `dry_run: true` の状態でログを確認してから、定期実行（毎週月曜 06:00 JST）に任せてください。
3. 失敗時はエラー画面のスクリーンショットが Artifacts にアップロードされます。

## 既知の制約

- サロンボードには公式APIがないため、UI変更で本スクリプトが壊れる可能性があります。壊れた場合は
  `npm run codegen` でセレクタを取り直してください。
- 「予約実績とクーポンの紐付け」は予約一覧画面に表示されるクーポン名をそのまま突き合わせています。
  クーポン名の表記ゆれ（全角/半角、末尾の空白など）がある場合は一致しないことがあるため、
  必要に応じて `src/reservations.js` / `src/coupons.js` の比較ロジックに正規化処理を追加してください。
